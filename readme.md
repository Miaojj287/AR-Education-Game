This source project is build in Unity 2022.3.15f1c1.
It can be run in the Android 9 to Android 13.

Install steps：
Download and open the "AR Education" file.
Then tap the install button.

Play steps：
Open the program--Click "PLAY" button--Choose Subject.
Chinese:Point the camera at the picture--Chinese, then move the camera around it.
English:Point the camera at the picture--English1 and English2, then press the words in the picture.
Music:Point the camera at the picture--Music, then press the note in the picture.
Geography:Point the camera at the picture--Geography, then, pull in or out the lens.

Tips:
All the pictures are in the "resource" file, you can print them first so that you can have a better playing experience.
You should make sure that your device supports Google AR framework before you install the program.
